# realman-s-experiments

睿尔曼（RealMan）机械臂 Python 实验脚本集合。基于 `Robotic_Arm` SDK（rm_robot_interface）通过 TCP 接口控制机械臂，覆盖连接、状态读取、关节/直线运动与安全限位等基础实验。

## 环境

- Python 3
- 依赖：`Robotic_Arm` SDK（rm_robot_interface）
- 机械臂默认地址：`169.254.128.18:8080`

## 文件说明

| 文件 | 内容 |
|------|------|
| `exp1.py` | 连接机械臂，读取末端位姿 `[x, y, z, rx, ry, rz]` 与关节角 `[q1..q6]` |
| `exp1_2.py` | 关节空间运动：第 6 关节在当前位置基础上 +5°（`rm_movej`，低速阻塞） |
| `exp1_3.py` | 直线运动：末端沿 Z 轴上移（`rm_movel`，低速阻塞） |
| `exp1_4.py` | 多点多段直线运动：当前位姿附近构造 3 个安全目标点并依次运动、返回起点 |
| `exp1_5.py` | 安全限位校验：检查目标点是否超出相对起始点 ±3 cm 的实验限位，超限则禁止发送运动指令 |

## 运行

```bash
python exp1.py
```

- 涉及运动的脚本（`exp1_2.py` ~ `exp1_4.py`）在执行前会要求按 Enter 确认机械臂周围安全。
- 关节角单位为度（°），末端位置单位为米（m），姿态单位为弧度（rad）。
- 运动速度 `v` 为速度百分比（1~100），示例中取 10 保证低速安全。

## 安全约定

- 所有目标点均相对于当前位姿/关节角小偏移生成，不硬编码绝对位置。
- `exp1_5.py` 演示了运动前限位校验：超出 ±3 cm 限位的目标点不发送运动指令。
